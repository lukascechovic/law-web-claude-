# WINGS Product Images

Place 5-8 high-quality product photos here.

## File Naming Convention

```
wings-01.webp
wings-02.webp
wings-03.webp
wings-04.webp
wings-05.webp
wings-06.webp
wings-07.webp
wings-08.webp
```

## Image Requirements

- **Format:** WebP (preferred) or optimized JPG
- **Minimum width:** 1200px
- **Recommended height:** 800px
- **Max file size:** 500KB per image
- **Color space:** sRGB

## Suggested Image Types

1. Product shot (front view)
2. Product shot (side view)
3. Detail/close-up shot
4. Lifestyle shot (in use)
5. Packaging shot
6. Comparison shot
7. Installation guide shot

## After Adding Images

Copy or symlink these to: `frontend/public/images/wings/`
