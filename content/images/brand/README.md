# Brand Assets

Place brand assets here.

## Required Files

```
logo-dark.png      - Logo on light background (transparent PNG, min 400px wide)
logo-light.png     - Logo on dark background (transparent PNG, min 400px wide)
logo-vector.svg    - Vector logo for scalability
favicon.svg        - Favicon icon
```

## Logo Requirements

- PNG files: transparent background, min 400px wide
- SVG file: scalable vector version
- Keep file size under 100KB for PNGs

## After Adding Assets

These will be served from `frontend/public/images/brand/`
