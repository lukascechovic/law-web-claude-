# HORIZON Product Images

Place 5-8 high-quality product photos here.

## File Naming Convention

```
horizon-01.webp
horizon-02.webp
horizon-03.webp
horizon-04.webp
horizon-05.webp
horizon-06.webp
horizon-07.webp
horizon-08.webp
```

## Image Requirements

- **Format:** WebP (preferred) or optimized JPG
- **Minimum width:** 1200px
- **Recommended height:** 800px
- **Max file size:** 500KB per image
- **Color space:** sRGB

## After Adding Images

Copy or symlink these to: `frontend/public/images/horizon/`
