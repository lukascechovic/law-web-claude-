# About Section Images

Place 3-5 images showing workshop, craftsmanship process here.

## File Naming Convention

```
about-01.webp
about-02.webp
about-03.webp
about-04.webp
about-05.webp
```

## Image Requirements

- **Format:** WebP (preferred) or optimized JPG
- **Minimum width:** 800px
- **Max file size:** 500KB per image
- **Color space:** sRGB

## Suggested Content

1. Workshop photo
2. Craftsmanship in progress
3. Tools/materials detail
4. Finished product showcase
5. Brand story image

## After Adding Images

Copy or symlink these to: `frontend/public/images/about/`
