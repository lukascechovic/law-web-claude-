# ARC Product Images

Place 5-8 high-quality product photos here.

## File Naming Convention

```
arc-01.webp
arc-02.webp
arc-03.webp
arc-04.webp
arc-05.webp
arc-06.webp
arc-07.webp
arc-08.webp
```

## Image Requirements

- **Format:** WebP (preferred) or optimized JPG
- **Minimum width:** 1200px
- **Recommended height:** 800px
- **Max file size:** 500KB per image
- **Color space:** sRGB

## After Adding Images

Copy or symlink these to: `frontend/public/images/arc/`
